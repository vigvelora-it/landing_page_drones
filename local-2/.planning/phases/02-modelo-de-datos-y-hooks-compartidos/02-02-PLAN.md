Add a small helper `closestCursorTarget(node: EventTarget | null): HTMLElement | null` that returns `node instanceof Element ? node.closest<HTMLElement>("[data-cursor]") : null`. Add `onPointerOver(event: PointerEvent)`: resolve `target = closestCursorTarget(event.target)`; if none, return; resolve `related = closestCursorTarget(event.relatedTarget)`; if `related === target` return (still inside the same target — ignore child-boundary crossings); otherwise set the cursor label text to `target.dataset.cursor ??
